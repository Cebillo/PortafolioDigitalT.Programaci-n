### **Unidad 1**

#### **Algoritmo**

Un algoritmo es un conjunto de pasos ordenados y finitos que se siguen para resolver un problema o realizar una tarea. Es fundamental en la programación porque permite indicar de forma clara qué acciones debe ejecutar una computadora para obtener un resultado.

#### **Pseudocódigo**
¿Qué es Pseudocódigo?

El pseudocódigo es una forma de escribir algoritmos usando un lenguaje sencillo y estructurado, parecido al lenguaje humano, pero con lógica de programación. No sigue reglas estrictas de un lenguaje real, por lo que es fácil de entender y sirve para planificar soluciones antes de programarlas.

<img width="918" height="606" alt="image" src="https://github.com/user-attachments/assets/ebcd489a-b62e-4913-8aaa-594222d5db76" />

#### **Diagrama de flujo**

Un diagrama de flujo es una representación gráfica de un algoritmo o proceso, utilizando símbolos y flechas para mostrar los pasos a seguir y el orden en que se ejecutan.

Sirve para visualizar y entender cómo funciona un programa antes de escribir el código, facilitando la organización y detección de errores.

<img width="451" height="975" alt="image" src="https://github.com/user-attachments/assets/b4b3afd8-7740-4829-968a-5b03512a0a60" />


#### **Prueba de escritorio**
Una prueba de escritorio es una técnica para verificar el funcionamiento de un algoritmo o programa paso a paso, sin ejecutarlo en la computadora.
Consiste en simular manualmente cómo se comporta el programa, usando valores de entrada y anotando los resultados en cada paso, generalmente en una tabla.

#### **Lenguajes de programación**

**C** = El lenguaje C es un lenguaje de programación de propósito general, creado para desarrollar sistemas y aplicaciones de manera eficiente. Se caracteriza por ser rápido, estructurado y cercano al hardware, lo que permite tener un mayor control sobre la memoria y los recursos del computador.

Es uno de los lenguajes más importantes en la programación, ya que ha servido como base para muchos otros lenguajes modernos y es ampliamente utilizado en el desarrollo de sistemas operativos, software y programas de alto rendimiento.

**Java** = El lenguaje Java es un lenguaje de programación de propósito general, orientado a objetos y ampliamente utilizado en el desarrollo de aplicaciones. Se caracteriza por ser portátil, lo que significa que un programa puede ejecutarse en diferentes sistemas sin necesidad de modificaciones.

#### **Programación por bloques**
La programación por bloques es una forma de programar utilizando elementos gráficos (bloques) que se encajan entre sí, en lugar de escribir código con texto. Cada bloque representa una instrucción o acción, como mover, repetir o tomar decisiones.

#### **Ejercicio con estructura secuencial**
**Planteamiento del problema**
Una empresa desea calcular la comisión de tres vendedores.

Cada vendedor recibe el 40% de sus ventas como comisión.

Se requiere:

Calcular la comisión de cada vendedor

Calcular el total de comisiones a pagar

**Análisis del problema**

📌 Datos de entrada:

A1 = 30000 (ventas vendedor 1)

A2 = 29000 (ventas vendedor 2)

A3 = 33000 (ventas vendedor 3)

📌 Proceso:

com1 = A1 * 0.4

com2 = A2 * 0.4

com3 = A3 * 0.4

total = com1 + com2 + com3

📌 Salida:

Comisión de cada vendedor

Total a pagar
