###  **Unidad 1**

####  **Algoritmo**
Un algoritmo es un conjunto de pasos ordenados y finitos que se siguen para resolver un problema o realizar una tarea. Es fundamental en la programación porque permite indicar de forma clara qué acciones debe ejecutar una computadora para obtener un resultado.

<img src="https://github.com/user-attachments/assets/434760f8-9313-4f60-a211-d54e96341ad7" width="500">



####  **Pseudocódigo**
El pseudocódigo es una forma de escribir algoritmos usando un lenguaje sencillo y estructurado, parecido al lenguaje humano, pero con lógica de programación.

<img src="https://github.com/user-attachments/assets/ebcd489a-b62e-4913-8aaa-594222d5db76" width="500">



####  **Diagrama de flujo**
Un diagrama de flujo representa gráficamente un algoritmo mediante símbolos y flechas.

<img src="https://github.com/user-attachments/assets/b4b3afd8-7740-4829-968a-5b03512a0a60" width="400">



####  **Prueba de escritorio**
Es una técnica para verificar paso a paso un algoritmo sin ejecutarlo.
